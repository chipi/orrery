## Operational learnings (save yourself the pain)

- **git push hangs on the macOS `osxkeychain` helper** (login keychain wedges). Bypass: `git -c credential.helper= -c credential.helper='!gh auth git-credential' push …`. `gh` itself works throughout.
- **The pre-push hook runs a *smart* preflight** that, for **i18n-only** changes, skips the full vitest run — so a test regression from a locale change can slip to `main` (it happened: `fly-event-catalog.test.ts`). **Run `npx vitest run` locally after any message-file change.**
- **Deploy mechanics that worked:** tag push → `release.yml` auto-creates/updates the Release from the CHANGELOG section (idempotent, re-tagging updates it). `deploy-prod.yml` (workflow_dispatch, blank input = main HEAD) builds the bundle fresh + compose-up + healthcheck + `validate-prod`. `regen-snapshots.yml` (workflow_dispatch) regenerates Linux visual baselines on CI and commits them back (found no changes this cycle). Staging = GitHub Pages "Deploy preview", auto on green.
- **iOS device install:** `cap run ios` only lists simulators; install to a physical device with `xcodebuild -workspace ios/App/App.xcworkspace -scheme App -destination 'id=<UDID>' -allowProvisioningUpdates build` then `xcrun devicectl device install app`. Automatic signing (team `3P3PX275ZM`) works; the phone must be unlocked + trusted.
