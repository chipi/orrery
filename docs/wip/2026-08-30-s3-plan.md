# S3 plan — the `/lab` route: Notebook + Focus (v1 home)

_2026-08-30 · epic #458 · S3 = RFC-037 §10 S3 + UXS-015 · the FIRST visible surface of the
flagship — everything S1/S2 built becomes a page. Status: DRAFT for operator good-to-go._

> **Why a planning pass.** S3 is design-heavy (the notebook UX + the card interaction), and it
> wires five separate things together (route, card model, the S2 registry, the S2 FigureRenderer,
> KaTeX, paraglide i18n) plus the linear-recompute engine Fable-5 pulled *out* of T2 into S3. The
> visual anchors already exist (`docs/prototypes/lab/{notebook,focus}.html`) and gate Slice-0.

## 1 · Grounding (exists vs greenfield)
- **Reuse:** the S2 **registry** (`$lib/physics/registry` — 8 formulas, 2 goals) · the S2
  **`FigureRenderer.svelte`** (+ approved lab background) · `src/lib/katex.ts` `renderKatex()` ·
  `ScienceChip`/`WhyPopover` components · the `/science` route pattern (`[tab]`+layout) · paraglide
  (`messages/en-US.json` → `i18n:compile`) · the frozen `Card`/`Notebook`/`Goal` types in `spec.ts`.
- **Greenfield (S3 builds):** the `/lab` route · the **Card component** (formula instance UI) ·
  the **Notebook** + **Focus** views · the **serialization codec** (URL + localStorage + `.orrlab.json`) ·
  the **linear-DAG recompute** (card N consumes card N-1's output) · the authored **`lab.*` i18n keys**.

## 2 · The Card (the atom, from UXS-015) — every part maps to something shipping
| Card part | Source |
|---|---|
| Title (Bebas) | `FormulaDef.titleKey` → `t()` |
| Equation (KaTeX) | a per-formula LaTeX string (new, small) → `renderKatex()` |
| Parameter controls | `FormulaDef.inputs` (`FieldSpec`) → sliders / enum-select / body-picker |
| Live figure | `FormulaResult.figure` → **`FigureRenderer`** (S2) |
| Readout | `FormulaResult.values` → `.readout-grid` teal cell |
| Why? / derivation | `WhyPopover` (gold) → `citationKey` → `/science` |
| Honesty line | already in `FigureRenderer` (provenance + assumptions) |
| Fail-honest | `status.ok:false` → mars-red readout + `reasonKey` |
| **Upstream-failed (B3)** | a wired input whose upstream card is `ok:false`/absent → mars-red "upstream failed", NEVER fall back to the default (a fake verdict under a red card = honesty violation) |

**Card state machine (B3):** `ok` · `fail-honest` (this formula infeasible) · **`upstream-failed`** (a
`wiresFrom` source produced no value — do NOT compute from the default; surface it). The wire
resolves to a value ONLY when the upstream card is `ok` AND declares that output.

## 3 · Sub-slices (each = commit + preflight-green; per-child cadence)
- **S3a — the Card component + `/lab` route shell.** One live card from the registry: sliders →
  recompute → `FigureRenderer` + readout + Why? + the 3 states above. Renders any registered formula.
  **B1 (KaTeX is server-only, ADR-034):** the card does NOT call `renderKatex` at runtime — a
  `/lab` `+page.ts` with `prerender = true` emits an **equation-HTML map for the whole registry**
  at build (8 formulas via `FormulaDef.latex`), and the card looks up its formulaId. So S3a ALSO:
  registers `/lab` in `scripts/site-routes.mjs` prerender entries (uncrawled → 404 SPA fallback →
  katex ships to the browser), and imports KaTeX CSS for `/lab`. Momentum has no figure → the card
  omits `FigureRenderer`. Mobile: S3a acceptance includes the 390px dev-server screenshot (M-minor).
  (Visual anchor: `notebook.html` card.)
- **S3b — the Notebook view + linear recompute.** Render a **Goal** as an ordered, narrated column
  of cards; `+ADD CELL` (a formula-picker palette — **needs a design anchor, M6-minor**; prototypes
  show the button not the picker); the recompute so a wired step updates live (the M1 ladder is the
  shipping content). **M4: index-order recompute is sufficient — no topological sort** (a wire is
  honored only if its source is an *earlier* card; else → the B3 upstream-failed/unwired state).
  Full-notebook recompute per edit is trivially cheap for M1 (closed-form, ≤~95-pt curves) — **no
  memoization until the porkchop**. Recompute core lives HERE, not T2.
- **S3c — the Focus view + serialization codec.** One card full-screen (big figure + control rail;
  Focus = a URL-param mode, not a sub-route). The codec (B2 — the URL grammar is now freezable):
  - **URL-compact:** `?nb=1.<base64url>` — a **version prefix `1.`** (B2.2), then a minified
    `{f: formulaId, i: inputs, s?: selection, w?: [{from: <index>, out, to}]}[]` — **index-based
    wires** (B2.1: `Card.wires.fromCard` is an id; rehydrate ids on decode), and **`selection`
    INCLUDED** (B2.3: dropping a picked porkchop cell → silently different downstream result;
    `note`/`title` stay out). Measured: M1 6-card notebook = 630 chars, fits ~2 KB budget.
  - **`localStorage`** (session) + **`.orrlab.json`** (durable; `orrlab:1` version + preserve-unknown-fields).
  - **M4 codec boundary (untrusted input):** on decode, a wire is honored ONLY if `from` is an
    EARLIER card index; self/forward/cyclic wires → unwired → B3 state. A **round-trip property
    test** (`decode(encode(nb)) ≡ nb` minus excluded fields) + hostile-input cases (cyclic wires).
- **S3d — i18n authoring + wire `t`.** **M5: paraglide ids are snake_case (they become function
  names) — the registry's DOTTED keys (`lab.f.tsiolkovsky.title`) need a dot→underscore mapping.**
  Either the `t` resolver maps dot→underscore over `import * as m` (a manifest), or a rename sweep;
  decide at S3d head. Author every `lab.*` key referenced by `REGISTRY ∪ GOALS` + `lab.figure.unsupported`
  into `en-US.json` + translate ×14 (machine, per operator locale policy — real budget, not "+i18n").
  Route `fidelityLabel` through `t` (returns a key; EN honesty line renders identically). Key-manifest
  guard test: every referenced `*Key` resolves. **M8: interim (S3a–c) `t` = key-passthrough** — if
  sub-slices push to main before S3d, `/lab` shows raw keys on staging; land S3a–e as one push block
  OR accept that. (`latex?` strings get a build-time `renderKatex` test — `throwOnError:true` gates bad LaTeX.)
- **S3e — a11y + mobile + e2e + nav.** Notebook mobile-first (44px targets, single-column; card
  already 390px-checked at S3a); keyboard-native; `?debug=1` tab; register `/lab` in the app nav.
  **M7: the register golden-master is a Playwright E2E** (assert the `fidelity-*` classes + dasharrays
  in a rendered `/lab` figure's DOM) — **NOT** vitest component-mount infra (zero such tests exist;
  would need a new devDep + approval). Playwright e2e desktop+mobile. **`preflight:coverage` before
  any push** (codec + recompute are new counted `.ts` under the frozen thresholds).

## 4 · Contract-freeze decisions for S3 (the good-to-go substance)
1. **✅ URL-compact grammar** — RESOLVED (Fable-5 pre-S3 B2), spec'd in S3c: `?nb=1.<b64url>`,
   version prefix, index-based wires, `selection` in / `note`+`title` out, round-trip + hostile-input
   tests. Measured 630 chars for M1. Freeze the codec at S3c head.
2. **✅ Per-formula LaTeX** (operator-approved 2026-08-30): add `FormulaDef.latex?: string` — the
   equation lives with the formula (one place; the MCP can expose it too). A tiny additive re-freeze
   of the frozen contract (append an optional field — no shape breaks). Done at S3a.
3. **✅ Recompute** — linear-DAG in S3b (topological over `wiresFrom` indices; the wire-integrity
   gate from S2c guarantees no cycles at the linear level).
4. **✅ Route** — `/lab` (Notebook default); Focus as a mode, not a sub-route (URL param). Canvas is S5/T2.
5. **✅ i18n** — keys authored in S3d; `t` = paraglide resolver; user Notebook `title`/`note` stay free text.
