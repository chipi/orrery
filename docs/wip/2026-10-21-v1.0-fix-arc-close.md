### Second pass: items 6–10 and 13–14 of the open list (operator's ticks, 2026-10-21)

- **#601 CSP:** hash-mode `kit.csp` puts a per-page `<meta>` CSP listing that page's inline
  script hashes, so the nginx header's `'unsafe-inline'` no longer lets an injected inline
  script run. `src/lib/csp-hashes.test.ts` pins the two fixed hashes (`app.html`'s viewport
  script, Svelte's `this.__e=event` handler) and every Umami host. 0 CSP violations on 15
  routes, desktop and mobile. The Umami SRI pin was already in place (`5fde30815b6`).

  the file. Verified on dev: the event arrives with frames `core.ts readJson` ← `core.ts get`.

  `--color-accent-text`, the quality-unknown chip, agency badges via `readableTextOn()`); the
  a11y gate fails on serious as well as critical.
