# Tech-debt Phase 5 — what users download

Branch `tech-debt/phases` (never merged to main from this arc). Runs after the
i18n phase ([2026-10-30-i18n-phase-plan.md](2026-10-30-i18n-phase-plan.md)).
Sizes below are static client JS per route node (the node's import closure from
`.svelte-kit/output/client/.vite/manifest.json`), raw / brotli q11.

## 1. The 3 MB messages chunk — done

Cause: three places looked messages up by a computed key on the paraglide
module (`science_tab_<tab>` in three /science files, `galaxy_name_<id>` in
`galaxy-label.ts`, `t(key)` in `lab/t.ts`). Indexing the module makes the
bundler keep every message, so one ~3 MB chunk loaded on /science, /explore and
/lab.

Fix: explicit tables of message functions — `src/lib/science-tab-label.ts`
(typed `Record<ScienceTabId, …>`, so a new tab without a message fails
typecheck), the galaxy table in `galaxy-label.ts`, and
`src/lib/lab/lab-messages.ts` (1,099 `lab_*` messages, generated by
`scripts/i18n-tools/gen-lab-messages.mjs`).

Guards: `scripts/i18n-tools/no-dynamic-messages.test.ts` (no computed lookup or
re-typing of the messages module anywhere in `src/`); the lab parity test now
resolves keys against the lab table, fails when the table is stale, and fails
when a non-`lab.` key reaches `t()`.

Found on the way: the `planets` tab had no `science_tab_planets` message and
showed English "Planets" in every locale. Added in all 14, upper-cased like
the other tab labels, using the word the site already uses
(`credits_category_planet`).

| Route | Before | After |
| --- | --- | --- |
| /science/[tab] | + catalogue chunk ¹ | 152 KB / 50 KB br |
| /explore | + catalogue chunk ¹ | 2,127 KB / 558 KB br |
| /lab | 5,689 KB / 1,544 KB br | 2,868 KB / 756 KB br |

¹ The catalogue chunk was 3,078 KB / 763 KB br; the route totals before the
fix were not measured.

What is left in /lab (a 2,354 KB chunk) is the Lab's own 1,099 messages:
Paraglide 2.21 compiles every message with all 14 locales inline. It has no
option that ships one locale to a static (prerendered) site —
`experimentalMiddlewareLocaleSplitting` needs a server middleware. Not worked
around here; decide with item 3.
