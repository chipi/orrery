# 0.9.5 handover — /fly flight and descent work left after 0.9.4

Written 2026-11-03, when 0.9.4 was cut. This is the `/fly` flight-and-descent list only; the
technical-debt list stays in [`2026-10-31-tech-debt-open-inventory.md`](2026-10-31-tech-debt-open-inventory.md).
Background, numbers and sources for everything done so far:
[`2026-11-02-fly-flight-and-descent-analysis.md`](2026-11-02-fly-flight-and-descent-analysis.md)
(§8 Mars, §9 Moon, §10 the rest).

**Scope rule (operator, 2026-11-02):** no return flights. A mission keeps its one descent.

## Start here — in this order

### 1. Earth capsule descents (32 profiles)

The only descent family not checked against sources (the analysis note said 31; the repo has
32). Archetype `EARTH_CAPSULE_REENTRY` in `static/data/descent-profiles/`: apollo7, apollo8,
apollo9, apollo-soyuz, aurora-7, faith-7, freedom-7, friendship-7, gemini3, gemini4, gemini6a,
gemini7, gemini8, gemini12, inspiration4, liberty-bell-7, polaris-dawn, shenzhou-1, sigma-7,
skylab-2, skylab-3, skylab-4, soyuz-1, soyuz-11, voskhod-1, voskhod-2, vostok-1 … vostok-6.

- `DescentScene.svelte` shows Earth re-entries on a clock scaled to a fixed 840 s
  (`NOMINAL_EARTH_REENTRY_S`), because the model's path runs ~100 min. That scaling hides the
  real problem; once the profiles fly their sourced timelines it should go.
- Check per capsule: entry interface altitude and speed, angle, peak g, drogue and main chute
  altitudes, splashdown / landing speed and time from entry. Mission reports first (NASA
  SP / TM, Roscosmos, CMSA); `docs/wip/2026-07-19-tier1-earth-orbit-reentry.md` lists what was
  approximate.
- Method that worked for Mars, Moon and Venus: research JSON with sources → fit only the
  declared estimates (`estimatedFields`) to the sourced timeline → re-derive arrival fields
  (`npx tsx scripts/backfill-descent-arrival.ts`) → `descent-profiles.test.ts` bands.
- Earth uses a single exponential atmosphere; if the timelines will not fit, a measured profile
  (US Standard Atmosphere 1976) goes into `descent-atmosphere-tables.ts` like Venus, Titan and
  Jupiter.

### 2. Missing cruise events on ten Moon flights

Apollo 8, 10, 12, 14, 15, 16, Chang'e 1, Luna 10, Lunar Prospector and SMART-1 have no
`flight.events`, so their TLI, LOI, TEI and descent beats never fire in `/fly`. Each new event
needs its label and description in all 14 locales by hand (`i18n-src/<locale>/missions/moon/
<id>.json` → `flight_events`, matched to the base event by MET). Times from the mission
reports, not estimated.

Also: Clementine's TCM-1 and TCM-2 (days 10 and 10.24) were moved after the TLI in 0.9.4 but
their days are still unsourced; the NRL mission report would give them.

### 3. Vehicle models

- **Zhurong landed model** — Tianwen-1's descent falls back to the generic Mars lander.
- **Small-body craft** — Hayabusa, Hayabusa2, OSIRIS-REx and NEAR Shoemaker all descend as one
  generic "asteroid sampler bus". Each needs its own model (sampler horn / TAGSAM, solar
  arrays, NEAR's fixed high-gain dish).

### 4. Missing descents

- **Beagle 2** (carried by Mars Express): EDL profile and model.
- **DART impact** — an impact, not a landing; needs its own terminal beat.
- **The Vega balloons** — only the landers fly; the balloons were extracted at ~61–55 km and
  floated ~46 h at 53–54 km (PDS Vega host catalog; sources already in the Vega profiles).
- **The two Starship Mars flights** — they have a profile but no `flight` block (no events,
  no interplanetary profile).

## Other open items from the analysis

- **Orbit-insertion plume for Moon missions** — the cislunar scene has no OI plume (tried and
  reverted in 0.9.4; the `/fly` cislunar frame has no ship-attached plume anchor).
- **Event timing** — the 86 flyby events' closest-approach distances and times, and the cruise
  TCM times across all missions, were never checked against mission records.
- **Model accuracy** — the dedicated EDL stacks (aeroshell shape, chute count, airbag bounce,
  skycrane cable length) were not compared with photos and mission reports.
- **Returns** — out of scope by the operator's rule above; listed so the next arc can ask.

## Tools

- Research notes from 0.9.4 (Mars, Moon, planetary EDL, orbit insertion) were scratch files and
  are not in the repo; their sources are copied into each profile's `provenance`.
- Profile checks: `npx tsx scripts/backfill-descent-arrival.ts` (arrival fields),
  `npx vitest run src/lib/physics/descent`, the `?debug=1` FLY tab on `/fly?mission=<id>&descent=1`
  (live altitude, speed, g, beat, outcome).
- e2e: `tests/e2e/fly-descent.spec.ts` mounts one mission per archetype.
