# Booster landings: sourced figures (2026-11-24)

Research pass (sonnet subagent, WebFetch summaries, not verbatim page reads). "Not found" means
no source was read for it; those values are estimates in the profiles.

## Falcon 9 first stage on a drone ship

Flight: Starlink 6-108 press kit (Feb 2026, booster's 30th flight, A Shortfall of Gravitas). Times
are the kit's planned "All Times Approximate", not webcast telemetry. The kit was read from a
third-party mirror (sky-brokers.com); the SpaceX original was not fetched.

| Figure | Value | Source |
|---|---|---|
| MECO / stage sep | T+2:24 / T+2:28 | press kit |
| Entry burn | T+6:08 to T+6:34 | press kit |
| Landing burn start | T+7:55 | press kit |
| Touchdown | T+8:20 | press kit |
| Grid fins | 4, X-wing, stowed on ascent, deployed on re-entry; titanium | Wikipedia, Falcon 9 first-stage landing tests; Falcon 9 |
| Landing legs | 4, ~18 m span, deploy just before landing | Wikipedia, Falcon 9 first-stage landing tests |
| RCS | nitrogen cold-gas thrusters for coast/descent attitude (placement not sourced) | Wikipedia, Falcon 9 |
| Diameter / dry mass | 3.7 m / 25,600 kg | Wikipedia, Falcon 9 |
| ASDS deck | 52 x 91 m (170 x 300 ft), Marmac 300-series barge; ASOG = Marmac 302 | Wikipedia, Autonomous spaceport drone ship |
| ASDS features | 4 azimuth thrusters (originally 300 hp, 1 m nozzles); steel blast wall (OCISLY); Octagrabber robot; X-in-circle pad marking | same |

Not found: altitude and speed at each burn, downrange distance, which Merlins fire in each burn,
stage-only length, deck width with the wings, deck colour.
