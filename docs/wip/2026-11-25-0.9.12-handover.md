## Lessons from the 0.9.11 release (so they are not paid for twice)

- **Run all three e2e projects locally before the release push**: desktop-chromium,
  mobile-chromium and **mobile-landscape-chromium** (Pixel 5 landscape). The landscape project found
  two regressions that desktop and portrait passed: the drawer tabs hidden beside an open site, and
  a tap that clicked through the panel it opened. Its full run takes about an hour, so run it in
  the background with `--workers=1` and watch the log.
- **When a test fails on the branch and passes on main, bisect it by building commits in a
  scratch worktree.** A fresh worktree needs the generated data before `vite build`:
  `npx svelte-kit sync`, `npm run i18n:compile`, `npm run build-i18n-bundles`,
  `npm run build-science-index`, `npm run build-glossary`, `npm run precompute-porkchops`. Symlink
  `node_modules` from the main checkout and remove the worktree afterwards.
- **Phone taps on the 3D scenes are handled on `touchend`**, which now calls `preventDefault()` so
  the browser's emulated click does not land on what the tap just opened
  (`SurfaceScene.svelte`, `onTouchEnd`). Any new tap-to-open on a canvas needs the same.
- **The landscape phone keeps the drawer tabs and INDEX beside an open site** (operator decision
  2026-11-24, the 0.9.9 behaviour). The portrait phone hides them in close-ups
  (`mobileDrawerHidden`).
- **The /fly route budget was raised** with the operator's go: 500 KB eager, 165 KB lazy
  (`scripts/route-budget.json`). The way-home and booster-return scenes are lazy-loaded to stay
  inside it. A new /fly scene should be lazy too.
- **Three untracked `scripts/*.tmp.mjs` files are not ours** (`mobile-audit`, `pinch-probe`,
  `route-coverage`). They fail the pre-push Prettier check, tag pushes included. With the operator's
  approval, move them to a scratch folder for each push and put them back afterwards. Do not delete,
  format or commit them.
- **`gh run watch` can return before the run ends.** For the release CI watch, loop on
  `gh run view <id> --json status` until `completed`.
- **Release order** (unchanged): version bump and CHANGELOG in the arc PR, `route-lastmod` last on a
  clean tree, `check-version-sync`; merge; CI and docker-e2e green on the merge commit; deploy;
  `orrery-deploy-verify`; tag and Release; IndexNow on the operator's go. Merge, deploy, tag and
  IndexNow each need the operator's go.
