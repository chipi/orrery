# S2 plan — registry + FigureSpec + renderers + mechanics + Goal model

_2026-08-29 · epic #458 · implements RFC-037 §4/§5 + Amendment 01 (A01.1/A01.2/A01.2a/A01.3/A01.4)._
_Status: DRAFT for operator good-to-go + a pre-S2 contract-freeze review. S1 (kernel) LANDED._

> **Why S2 is different from S1.** S1 was a mechanical move (near-autonomous). S2 **builds new
> contracts** — the shapes every downstream slice (goals, MCP, Lab views) depends on. Freeze
> them wrong and every later slice pays. So the load-bearing part of this plan is §3 (the
> freeze decisions), not the file list.

## 1 · Grounding (what exists vs greenfield, verified post-S1)
- **Exists / reuse:** the kernel (`$lib/physics/*`, sealed); `/plan` porkchop = the existing
  "formula → live figure" loop (**canvas-2d** — UXS-015 wants deterministic **SVG**, so the Lab
  renderers are new); `src/lib/katex.ts` (equations); `ScienceChip` + `WhyPopover` (card parts);
  `StationBlueprint.svelte` (teal-grid look reference).
- **Greenfield (S2 builds):** `FormulaDef` + the formula registry · `FigureSpec` type + SVG
  renderers · the `Goal`/`GoalStep` model · the `mechanics/` kernel domain · the coverage CI.

## 2 · The split (Fable-5 r4 M-5: S2 can't be one slice)
- **S2a — contracts + registry + FigureSpec + SVG renderers.** Freezes the contracts (§3). Ships
  ONLY M1's renderers (force-diagram, curve, dv-waterfall) — demand-driven, rest pulled per goal.
- **S2b — `mechanics/` domain.** Greenfield formulas (M1 rungs first), demand-driven.
- **S2c — Goal model + coverage CI.** `Goal`/`GoalStep`, `tier`/`prereqs`, bidirectional ledger.

## 3 · CONTRACT-FREEZE DECISIONS (the good-to-go substance)

Each is frozen at **S2a**. ✅ = my recommendation (I'll proceed unless you redirect); ⚠️ = a
genuine fork I want your call on before freezing.

1. **`FormulaDef<I>`** ✅ — `{ id, schema: JSONSchema (inputs+units+server caps), compute(i)→FormulaResult, tier: number, prereqs: string[] }`. Registry = a `Map<id, FormulaDef>`; one place to add a formula; MCP tools + palette + coverage all derive from it.
2. **`FormulaResult`** ✅ — `{ values: Record<string,{value,units}>, figure?: FigureSpec, status: {ok:true}|{ok:false,reasonKey}, assumptions: string[] /*i18n keys*/, epochAgeDays? }`. (Fable-5: assumptions + reason are i18n KEYS; epochAgeDays numeric.)
3. **`FigureSpec` + fidelity axis** ✅ — the union (transfer-ellipse · porkchop · dv-waterfall · force-diagram · curve · orbit · ground-track · sky-chart · entry-corridor · cislunar-eci) each carrying `provenance: { fidelity: 'computed'|'geometric'|'replayed-published', module }` + `assumptions`. Kernel emits ONLY `computed`. Renderers keep registers visibly distinct (rendered-SVG golden-master enforces it).
4. **i18n = message KEYS, never raw prose** ✅ (Fable-5 r5 MAJOR-2) — `Goal.titleKey`, `GoalStep.narrativeKey`, `assumptions`, `reasonKey` all reference the paraglide bundle. Frozen so `.orrlab.json` never embeds locale-bound text.
5. **⚠️ M4 cell-selection-as-wire** — how does picking a porkchop cell become a card *output* another card consumes? This is a NEW interaction primitive (Fable-5 r4). Options: (a) a `selection` output field on the FigureSpec-bearing card that emits the picked (depDay, arrDay); (b) a generic "interactive figure → value" socket. **Recommend (a)** — narrower, matches the porkchop; freeze the field shape now even though wiring lands at M4. **Want your steer.**
6. **⚠️ D10 constants-home** — S1 found `MU_SUN` defined 3× in DIFFERENT UNITS (4π² AU³/yr² vs km-family) + 2 GMST impls. S2 must pick ONE `util/constants` home and unify **by value+unit**, not name. **Recommend:** a single `physics/util/constants.ts` keyed by body+quantity+unit; migrate the duplicates, add a test asserting cross-module agreement. **This is a real cleanup with a wrong-number risk — want to confirm scope (do it fully in S2a, or a dedicated S2a.1?).**
7. **Serialization / `.orrlab.json`** ✅ — one codec: URL-compact (shareable) + localStorage (session) + `.orrlab.json` (durable) with a **version field** frozen now (Fable-5 r5 m). Card/Goal are keys-not-prose so documents are locale-portable.
8. **Renderer scope** ✅ — S2a ships the FigureSpec type + the register system + **only M1's 3 renderers**; every other renderer is pulled by the goal that first needs it (demand-driven, Fable-5 r4 M-5). SVG, styled sketchy-but-exact on the teal grid.

## 4 · S2b — `mechanics/` domain (demand-driven)
Ships exactly the M1 rungs first: **F=ma, weight (m·g), momentum/thrust, TWR** + **free-fall,
projectile**. Each = a `FormulaDef` in the registry + a `FigureSpec` + unit tests + citations.
Reuses the D10 constants home + per-body helpers (`bodyGravity`/`bodyAirDensity`). Friction /
collisions / rotational / fluids / thermo stay OUT until a goal pulls them (Fable-5 r1 MAJOR-3).

## 5 · S2c — Goal model + coverage CI
- `Goal { id, titleKey, family, tier, prereqs: string[], path: GoalStep[] }` ·
  `GoalStep { formulaId, narrativeKey, wiresFrom?: {fromStep,output,toInput}[] }` (array — Fable-5 r2).
- `FormulaDef.tier`/`prereqs` — the concept graph (v1 renders flat Notebooks; skill-tree deferred).
- **Bidirectional coverage CI** (Fable-5 r5 NEW-1): every registered FormulaDef reachable from ≥1
  Goal AND every kernel capability on the S2 coverage manifest has a Goal. Arming schedule:
  goal→formula gate arms at the first authored goal (M1, S3); built→goal is a release-exit gate.

## 6 · Sizing + sequencing
- **Critical path:** S2a (contracts frozen) → S2b ∥ S2c → (S3 builds M1 on them).
- **S2a is the big one** (contracts + FigureSpec + 3 renderers + the freezes) — the rest hang off it.
- Each sub-slice = tests-in-slice + preflight-green (per-child commit cadence). S2 lands via the
  §4b protocol (post-slice Fable-5 holistic + full preflight + e2e-if-warranted — S2 adds no route
  yet, so e2e is light until S3).
- Zero new runtime deps in S2 (KaTeX present; `@modelcontextprotocol/sdk` is S4).
