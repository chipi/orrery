Lambert 문제

두 위치와 비행 시간이 주어졌을 때, 이들을 연결하는 궤도를 찾는 것 — 모든 행성 간 궤적의 핵심 문제입니다.

101 · zoom in

Hohmann 전이는 한 궤도에서 다른 궤도로 가는 가장 경제적인 경로이지만, 대부분의 임무는 실제로 Hohmann을 따르지 않습니다. 그들은 특정 날짜에 출발하기를 원합니다 — 예를 들어, 특정 로켓이 준비되었을 때, 또는 특정 발사대가 사용 가능할 때 — 그리고 특정 날짜에 도착하기를 원합니다 — 예를 들어, 화성의 먼지 폭풍이 가라앉을 때까지 기다려서요. Hohmann은 선택의 여지를 주지 않습니다. Lambert는 줍니다.

Lambert의 질문은 수학보다 더 단순하게 들립니다: 저는 지점 A에 있고, 지점 B에 가고 싶으며, 정확히 이만큼의 날짜를 소요하고 싶습니다. 어떤 궤도를 따라야 할까요? Lambert는 1761년에 답을 기록했습니다 — 주어진 시간 내에 두 점을 연결하는 정확히 하나의 타원(또는 어느 방향으로 도느냐에 따라 때때로 두 개)이 존재합니다.

이것이 여러분이 보게 될 모든 porkchop plot의 핵심입니다. /plan의 porkchop에 있는 각 픽셀은 하나의 Lambert 문제입니다: '날짜 X에 지구를 떠나, 날짜 Y에 화성에 도착 — 비용은 얼마인가?' 색상이 답입니다. 이를 병렬로 만 번 해결하면 전체 지도를 한 번에 얻을 수 있습니다. Orrery는 이를 Web Worker에서 수행하므로 계산하는 동안 UI가 멈추지 않습니다.

Lambert 문제는 다음과 같이 묻습니다: 저는 여기 있고, 저기에 가고 싶으며, 이만큼의 시간이 있습니다. 어떤 타원을 따라야 할까요? 두 개의 위치 벡터와 비행 시간이 주어지면, 방정식은 고유한 전이 궤도를 생성합니다(또는 두 개 — 중심 천체를 도는 긴 경로와 짧은 경로가 있습니다).

Hohmann 전이는 하나의 특정 Lambert 해입니다: 반대편 근점들에서의 위치, 전이 타원 주기의 절반과 같은 비행 시간. 어느 쪽 조건이든 당기면 — 다른 위치, 다른 시간 — 다른 타원을 얻습니다. 시간이 짧을수록, 더 편심된 타원, 더 높은 출발 에너지. 수학은 변하지 않습니다; 경계 조건만 바뀝니다.

Orrery는 `/plan`의 porkchop 셀 위로 마우스를 가져갈 때마다 Web Worker에서 Lambert 문제를 해결합니다. 각 셀은 다음과 같이 묻습니다: '날짜 X에 지구를 떠나, 날짜 Y에 화성에 도착 — ∆v 비용은 얼마인가?' 여러분이 보는 색상은 픽셀당 한 번씩 계산된 그 질문에 대한 답입니다.
