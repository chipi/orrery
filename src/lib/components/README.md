# src/lib/components — module map

Svelte components shared across routes, by family. Scene-specific ones live with their scene (`surface-scene/`, `lab/`); pure logic lives in `$lib/orbital`, `$lib/universe`, `$lib/surface-map`.

- **Root-layout shell** — `Nav`, `CommandPalette`, `DebugPanel`, `AudioOverlay`, `LanguageSuggestion`, `ExhibitOverlay`. `SensorySheet` is the unified settings sheet Nav opens; `LocalePicker` also sits in Nav. In `Nav`, every right-hand control wears the shared `.nav-btn` box (32 px fine pointer, 44 px touch; per-toggle rules carry state colours only), and High contrast / Share / Debug are one `moreItems` list rendered as the More menu (`#nav-more-menu`, outside the `<nav>`) and as phone drawer rows ([UXD-016](../../../docs/uxs/decisions/UXD-016-compact-nav-and-more-menu.md)).
- **Detail panels** — `Panel.svelte` is the shell (right drawer, mobile bottom sheet; props `grabFocus`, `zIndex`, `mobileSheet`). Content panels wrap it: `PlanetPanel`, `SmallBodyPanel`, `SatellitePanel`, `SunPanel`, `BeltPanel`, `MessagePanel`, `StarPanel`, `MissionPanel`, `FleetEntryPanel`, `StationModulePanel`, `PhasePanel`, `RegimePanel`, and the /explore-scale `MilkyWay` / `LocalGroup` / `LocalSheet` / `Virgo` / `Laniakea` / `CosmicWeb` / `DeepSky` / `Exoplanet` / `BlackHole` panels. Parts: `PanelTabRow`, `PanelHeroImage`, `PanelLightbox` (full-screen gallery viewer: pass `images={gallery}` and it steps through them), `AgencyRow`, `ScienceCard`, `ScienceChip`.
- **Named `*Panel` but NOT on the shell** — `ConicSectionPanel` (/fly overlay), `ScienceLayersPanel` (Science Lens), `SiteStoryPanel` (surface site story). `EarthObjectPanel`, `MuseumPanel`, `ObservatoryPanel` live in `surface-scene/`.
- **/fly** — `LaunchScene` / `CoastScene` / `DescentScene` (the flight acts; math in `$lib/orbital`), `LaunchTelemetry`, `AscentLosses`, `SpacecraftInfoCard`, `FlightDirectorBanner`; `PhaseMarkerLabel` (cislunar markers) vs `FdPhaseMarkerLabel` (the four FlightDirector stages).
- **/explore v2** — `StarIndex`, `StarPortrait`, `ConstellationFinder`, `HrDiagram`, `MassPeriodChart`, `CausalityMap`, `ExploreScalePicker`, `ExploreBodyIndex`.
- **Chip** — `Chip` (toggle / choice / action / link; the one control for every toggle, filter, choice and HUD action), `ChipGroup` (radiogroup arrow keys), `ResetViewButton`, look in `src/lib/styles/chip.css` ([UXD-014](../../../docs/uxs/decisions/UXD-014-one-chip-and-filter.md)); a component never writes its own chip rules.
- **Surface HUD** (used by `SurfaceScene`) — `ViewToggleButton`, `View3dControls`, `LayerChipRow` (the one flat layer-chip row, also used by Explore; UXD-015), `TierContextCard`, `TacticalScan`, `LensLegend`, `Panorama*`. **Stations** — `StationBlueprint`, `StationAssemblyControl`, `StationTimelineStrip`, `StationOrbitBanner`.
- **Look-alikes** — `EpochTimelineStrip` (/missions, /fleet) vs `TimelineNavigator` (/missions year window); `MediaPlayer` (modal) vs `VideoThumb` (resting tile).
- **Debug** — `DebugPanel` (`?debug=1`) shows page tabs registered via `DebugPanelRegistrar` / `debug-panel-context.ts`; also `RenderingDebugRegistrar`, `FlybyDebugViewer`, `AscentCameraDebug`.
- **Attribution/links** — `ImageCredit`, `LinkCredit`, `LearnLink` (ADR-051 rules).
- **Accent colour** — the accent tokens (`--color-accent`, `-hover`, `-soft`, `-edge`, `-strong`, `--color-state`, `--color-focus`, `--color-ok`) live in `src/lib/styles/tokens.css`; no component writes its own accent colour (UXD-001, A3); the chip active look is defined once in `chip.css`.
- **SEO** — `JsonLd` (schema.org data block in the head; build the data with `$lib/json-ld`), `SiteEntityPage` (the /moon|mars|venus/[id] entity page), `EntityIndex` (the A–Z list at the foot of /missions and /fleet; the scene routes link their entity pages from the INDEX panel instead, `SurfaceIndexPanel`, `ExploreBodyIndex` and `StarIndex`, whose black-hole rows link `/explore/black-holes/<id>`, ADR-096 items 11, 13 and 16) and `entity-page.css` (the content layout of every entity page: missions, fleet, sites, bodies, Lab formulas; ADR-096; container, title, lead and labels come from the page shell). **Page shell** — `src/lib/styles/page-shell.css` (loaded by `app.css`): `.page-shell`, `.page-crumb`, `.page-title`, `.page-lead`, `.page-section-label`, `.page-section-title` for every text page ([UXD-012](../../../docs/uxs/decisions/UXD-012-one-page-shell.md)).

Pointers: TA.md §components · AGENTS.md (i18n, mobile-first). No doc states why panels share one shell; the `Panel.svelte` prop comments are the only record.
